# Pitch outline (2D)

1. **Problem.** Trying a game idea takes days of setup before anything is playable. Cloud generators send your idea away and often return code that does not run.
2. **Beetle.** Type one prompt; a playable 2D game appears in seconds, made on this machine by a local model.
3. **Demo.** Fox platformer from one sentence, change it in words, switch to a bee tower defense, export one HTML file and play it offline.
4. **How it stays playable.** The model writes a design, not code. Seven genre kits, level generators, a validator and a bot that plays every level before the player does. Model-written game code is turned off.
5. **Numbers.** Six of six prompts became validated, playtested games in 10.7 to 16.9 s on `qwen3.5:4b`, zero validator errors, zero repairs (docs/RESULTS.md).
6. **Private by construction.** Ollama on loopback, no cloud model, exported games blocked from the network by their content security policy.
7. **Limits, said plainly.** Seven genres plus a set of classic templates; other ideas map to the closest genre. One machine, one designer.
8. **Next.** More genres and templates, a declarative way to describe new mechanics without executable model output, shared libraries.
